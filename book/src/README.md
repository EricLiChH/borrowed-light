# 欢迎回来

这不是从 `Hello, world!` 开始重读一遍语法。你曾经碰过 Rust；这条路径先诊断哪些知识仍然在，再把模糊的部分恢复成能用于项目的能力。

完整标准路径预计 30–40 小时；首个所有权样章需要 60–90 分钟。你将：

1. 用 6 道题判断是否需要完整学习本章。
2. 通过 move、immutable borrow、mutable borrow 三个实验恢复所有权心智模型。
3. 在浏览器中改代码并立即运行。
4. 在本地修复 3 个 Rustlings 练习。
5. 把同样的机制用于网站健康监测器领域模型。

之后继续完成 `Result`、trait、CLI、受控异步网络和带 SQLite 持久化的 Axum 服务。每一阶段都有独立的测试证据；忘记某块时可以跳回配方索引，不必从头重读。

## 两种入口

- 想系统恢复：先看[标准路径](guided/standard-path.md)，再从[入门诊断](guided/diagnostic.md)开始。
- 正在解决错误：直接查[配方索引](recipes/index.md)，按错误码或任务进入。

## 本地练习

```sh
cd exercises
rustlings
```

Rustlings 会自动重跑当前练习。输入 `h` 获得方向提示；完成后会显示参考解的位置。

> 源码已经公开，教材网站仍未部署。学习进度只保存在你的电脑上，不需要账户。
